# Cloudflare syntax themes

`cloudflare.json` is the original Zed theme copied from
https://github.com/kettanaito/zed-themes/blob/main/cloudflare.json (author: Ray.so).

`cloudflare-light.json` and `cloudflare-dark.json` adapt its syntax categories to
TextMate scopes for Shiki. Each token rule retains its original Zed category as
its name. Editor foreground/background and token colors are unchanged; italic
styles are preserved. Code uses weight 500 throughout instead of the original
700-weight Markdown headings/emphasis.

IBM Plex Mono is self-hosted under `src/content/public/fonts`: Latin WOFF2 files
for weight 500, normal and italic, with the upstream SIL Open Font License.
