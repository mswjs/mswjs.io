# source.mswjs.io

The website for [Source](https://source.mswjs.io), built with [VitePress](https://vitepress.dev).

## Commands

All commands are run from this directory:

| Command        | Action                                          |
| :------------- | :---------------------------------------------- |
| `pnpm install` | Installs dependencies (run at the repo root)    |
| `pnpm dev`     | Starts the local dev server                     |
| `pnpm build`   | Builds the production site to `.vitepress/dist` |
| `pnpm preview` | Previews the production build locally           |
